# Ultron

Poste de travail de développement piloté par une IA : une seule application,
façon VS Code, où « Ultron » pilote les fenêtres Claude Code, les terminaux et
les dépôts. Tourne en local (WSL2) avec l'abonnement Claude Code.

Voir `CLAUDE.md` pour la vision, les décisions et les garde-fous, et
`docs/windows-et-telephone.md` pour le lancement sous Windows et le téléphone.
